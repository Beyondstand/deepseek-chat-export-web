# DeepSeek 会话导出工具（纯前端网页）

**零安装、零后端、零权限**。三种用法：

- 💬 **一句话导出（日常）**：在 DeepSeek 里发送「**导出**」，本轮回答结束后**当前对话自动下载为 HTML**，页面右下角弹出确认；
- 🔗 **临时在线链接**：发送「**导出链接**」→ 本地导出之外，额外生成一个在线查看链接——默认是 TXT（60 分钟有效）；填了自建 Worker 地址后是 **HTML，被读取一次即自动删除**；
- 📚 **全量管理**：点书签后全部会话进入网页，可预览、单个或批量导出 HTML / TXT，也可对单个会话「生成在线链接」。

> 非官方工具，与 DeepSeek 无关。接口为非公开 API，随官网改版可能需要更新。

## 三步上手

1. 用浏览器打开本工具的网页地址（GitHub Pages / Cloudflare Pages 部署后的固定链接）；
2. 把页面上的 **「📚 DeepSeek 一键导出」书签** 拖到浏览器**书签栏**；
3. 登录 [chat.deepseek.com](https://chat.deepseek.com)。

之后：

| 想要 | 操作 |
|---|---|
| 导出**当前对话** | 在 DeepSeek 输入框发送 **`导出`**（`导出txt` → TXT） |
| 导出 + **临时链接** | 发送 **`导出链接`**（`导出txt链接` → 文本链接） |
| 导出**全部会话** | 在 DeepSeek 页面点击书签 → 工具页弹出，列表就绪后导出 |

第一次想先看看效果？访问 **`?demo=1`**。

> **书签栏在哪？** Chrome / Edge / Firefox 按 `Ctrl + Shift + B`（Mac：`⌘ + Shift + B`）即可显示，
> 然后把第 ② 步的书签链接拖到地址栏下方那条横栏上；Safari 在「显示 → 显示个人收藏栏」。
> 不想显示书签栏也可以点「手动创建？」，用 `Ctrl + D` 收藏后改地址，从书签菜单点击一样有效。

### 触发词

默认：`导出`、`导出HTML`、`导出html`、`导出网页`、`导出txt`、`导出TXT`、`导出文本`、`导出对话`、`导出记录`、`导出当前对话`、`导出链接`、`导出并分享`、`生成链接`、`/导出`、`#导出`、`/export`。
匹配规则是「消息**以触发词开头**」，可以说自然句子，例如
**「导出当前对话，并在回复里列出接下来的操作步骤」**。
含「链接/分享」的触发词会**额发生成临时在线链接**；含「txt/文本」则导出 TXT。
工具页可自定义触发词（改完把书签**重新拖一次**），推荐提示词支持一键复制。

**注意**：① 触发词会作为普通消息发给模型，DeepSeek 可能回一句无关的话，属正常；② 页面**整页刷新**后自动触发失效，再点一次书签即可恢复（SPA 内跳转不受影响）。

## 为什么需要「书签脚本」？

浏览器安全限制：任何外部网页都**不能直接调用 DeepSeek 接口**（跨域 CORS 被拦，可用 `tools/cors-test.html` 复现）。所以：

- **书签脚本**运行在 `chat.deepseek.com` 页面内（同源放行）：自动读取登录 token（**你不用复制粘贴**）、拉数据、按触发词导出；
- **工具网页**负责：会话列表、预览、渲染导出文件、接收脚本推来的数据（`postMessage`）。

没有服务器参与：数据只在你自己的浏览器标签页之间传递。

## 🔗 临时在线链接（把内容交给模型读取）

发送 `导出链接` 时，除本地下载外还会产生一个可分享链接，可贴给 DeepSeek（联网搜索能读网页）让它总结/处理，之后链接失效：

| 方案 | 内容 | 生命周期 | 设置成本 |
|---|---|---|---|
| **公共 TXT 服务**（tmpfiles.org，默认） | 纯文本 | 上传后 **60 分钟**过期 | 零设置 |
| **自建 Worker**（推荐） | **HTML（带排版）** | **被读取一次后立即删除**（另有 1 小时兜底） | 一次性部署 3 分钟，见下 |

### 自建 Worker 部署（可选）

1. 打开 `tools/worker.js`，复制全文；
2. dash.cloudflare.com → **Workers & Pages → 创建 Worker** → 粘贴 → 部署；
3. 该 Worker → **设置 → 变量 → 绑定 KV 命名空间**（名称必须为 `FILES`，新建空命名空间即可）；
4. 把 Worker 地址（`https://xxx.workers.dev`）填进工具页的「在线链接 Worker 地址」输入框——地址存在本机浏览器，发新书签后自动生效。

> 隐私：只有发送「导出链接」类触发词（或在网页上点了「生成在线链接」）才会上传；
> 「导出」「导出txt」永远只存本地。Worker 上传无鉴权（链接即钥匙，id 为 32 位随机串）。

## 导出的文件

| 格式 | 用途 |
|---|---|
| **HTML**（默认推荐） | 单文件、排版美观、含折叠的思考过程和搜索引用，可离线打开或转发分享 |
| **TXT** | 纯文本，兼容所有工具 |

文件名：`DeepSeek_<会话标题>_<时间戳>.html/.txt`。**纯前端方案中文件落在浏览器「下载」目录**（浏览器沙箱不允许网页静默写桌面）。

## 隐私说明

- 书签脚本在 DeepSeek 页面内**现读** `localStorage.userToken`，只用于同源 API 请求；不上传、不落盘、不出浏览器；
- 会话数据经 `postMessage` 直达你打开的工具页，无任何第三方服务器；
- 唯一例外：「导出链接」会按上述规则上传到临时托管（可改用自建 Worker，数据只经过你自己的账号）；
- 工具页无统计、无追踪。

## 部署（任选一个静态托管）

### GitHub Pages

仓库推到 GitHub → **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main` / `/ (root)` → 得到 `https://<用户名>.github.io/<仓库名>/`。

### Cloudflare Pages

dash.cloudflare.com → **Workers & Pages → Create → Pages** → Connect to Git（选本仓库，构建配置留空）或 Upload assets（拖入全部文件）→ 得到 `https://<项目名>.pages.dev`。

两者都可绑自定义域名；部署后书签链接由页面按当前地址自动生成。

> 临时演示也可以不部署：`cloudflared tunnel --url http://127.0.0.1:8766` 拿临时公网地址（会短暂暴露本地服务）。

## 兜底方案（不想用触发词）

网页底部支持直接粘贴：**DeepSeek 导出的 JSON**（控制台脚本产物 / 官方「导出全部历史对话」解压出的 conversations.json / 接口原始响应）或**任意对话文本**，点「按 JSON / 纯文本导入」即可预览导出。

## FAQ

**Q：发了「导出」但没下载？**
依次排查：① 书签是否是**重新拖过**的最新版；② 本轮回答是否已结束；③ 浏览器是否拦截下载；④ 页面是否整页刷新过（再点一次书签）。

**Q：发了「导出链接」，链接在哪里？**
脚本会在 DeepSeek 页面右下角弹出确认（含链接，已自动复制到剪贴板）；填了 Worker 地址且触发 HTML 模式时，链接被读取一次即删——**先自己打开验证，再发给模型**。

**Q：书签脚本安全吗？**
代码全公开（`tools/bookmarklet.js`，网页上也展示）；只在 DeepSeek 页面内同源请求 `chat.deepseek.com`，token 只放进请求头；额外的网络请求仅发生在「导出链接」（上传到 tmpfiles/你的 Worker）。

**Q：换账号 / 退出登录？**
token 每次点书签时现读，自动跟随当前登录账号。

**Q：Firefox / Safari 能用吗？**
能。本方案只用同源 fetch + postMessage + Blob 下载等通用能力。

**Q：导出的 HTML 里对话内容会被当代码执行吗？**
不会，全部转义（演示数据里故意放了 `<script>` 用于验证）。
