# DeepSeek 会话导出工具（纯前端网页）

**零安装、零后端、零权限**。两种用法：

- 💬 **一句话导出（日常）**：在 DeepSeek 里发送「**导出**」，本轮回答结束后**当前对话自动下载为 HTML**（发「导出txt」则 TXT），页面右下角弹出确认；
- 📚 **全量管理**：点书签后全部会话进入网页，可预览、单个或批量导出 HTML / TXT。

> 非官方工具，与 DeepSeek 无关。接口为非公开 API，随官网改版可能需要更新。

---

## 三步上手

1. 用浏览器打开本工具的网页地址（部署到 GitHub Pages 后即固定链接）；
2. 把页面上的 **「📚 DeepSeek 一键导出」书签** 拖到浏览器**书签栏**；
3. 登录 [chat.deepseek.com](https://chat.deepseek.com)。

之后：

| 想要 | 操作 |
|---|---|
| 导出**当前对话** | 在 DeepSeek 输入框发送 **`导出`**（或 `导出HTML` / `导出txt` 等触发词） |
| 导出**全部会话** | 在 DeepSeek 页面点击书签 → 工具页弹出，列表就绪后点「⬇ 导出」 |

第一次想先看看效果？访问 **`?demo=1`**（如 `https://you.github.io/repo/?demo=1`）。

### 触发词

默认：`导出`、`导出HTML`、`导出html`、`导出网页`、`导出txt`、`导出TXT`、`导出文本`、`导出对话`、`导出记录`、`导出当前对话`、`/导出`、`#导出`、`/export`。
匹配规则是「消息**以触发词开头**」——所以可以说自然的句子，例如
**「导出当前对话，并在回复里列出接下来的操作步骤」**（导出的同时让 DeepSeek 给你列行动清单）。
工具页上方可自定义触发词（改完把书签**重新拖一次**），页面还提供了推荐提示词一键复制。

**注意**：① 触发词会作为普通消息发给模型，DeepSeek 可能回一句无关的话，属正常；② DeepSeek 页面**整页刷新**后自动触发失效，再点一次书签即可恢复（SPA 内跳转不受影响）。

## 为什么需要「书签脚本」？

浏览器安全限制：任何外部网页都**不能直接调用 DeepSeek 接口**（跨域 CORS 被拦，可用 `tools/cors-test.html` 复现）。所以：

- **书签脚本**运行在 `chat.deepseek.com` 页面内（同源放行）：自动读取登录 token（**你不用复制粘贴**）、拉数据、并按触发词导出；
- **工具网页**负责：会话列表、预览、渲染导出文件、接收脚本推来的数据（`postMessage`）。

没有服务器参与：数据只在你自己的浏览器标签页之间传递。

## 导出的文件

| 格式 | 用途 |
|---|---|
| **HTML**（默认推荐） | 单文件、排版美观、含折叠的思考过程和搜索引用，可离线打开或转发分享 |
| **TXT** | 纯文本，兼容所有工具 |

文件名：`DeepSeek_<会话标题>_<时间戳>.html/.txt`。**纯前端方案中文件落在浏览器「下载」目录**（浏览器沙箱不允许网页静默写桌面）。

## 隐私说明

- 书签脚本在 DeepSeek 页面内**现读** `localStorage.userToken`，只用于同源 API 请求；不上传、不落盘、不出浏览器；
- 会话数据经 `postMessage` 直达你打开的工具页，无任何第三方服务器；
- 工具页无统计、无追踪，除拉取数据外可断网使用。

## 部署（任选一个静态托管，二选一即可）

### 方式一：GitHub Pages

1. 仓库推到自己 GitHub 账号；
2. **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main` / `/ (root)`；
3. 约 1 分钟后 `https://<用户名>.github.io/<仓库名>/` 即为工具地址，页面会自动生成指向自己的书签链接。

### 方式二：Cloudflare Pages

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Pages**；
2. 两种接法任选：
   - **Connect to Git**：授权 GitHub 选中本仓库 → 构建配置**全部留空**（纯静态无需构建）→ 保存部署；
   - **Upload assets**：直接把 `index.html`、`app.js`、`shared.js`、`style.css`、`demo-data.js`、`tools/` 拖进去上传；
3. 得到 `https://<项目名>.pages.dev`，打开后拖一次书签即可使用。

两者都支持绑定自定义域名；部署后书签链接由页面按当前地址自动生成，无需改代码。

> 临时演示也可以不部署：用 `cloudflared tunnel --url http://127.0.0.1:8766` 生成一个临时公网地址，
> 用完即关（注意这会把本地服务短暂暴露到公网）。

## 兜底方案（不想用触发词）

网页底部支持直接粘贴：**DeepSeek 导出的 JSON**（控制台脚本产物 / 官方「导出全部历史对话」解压出的 conversations.json / 接口原始响应）或**任意对话文本**，点「按 JSON / 纯文本导入」即可预览导出。

## FAQ

**Q：发了「导出」但没下载？**
按顺序排查：① 书签是否是**重新拖过**的最新版；② 本轮回答是否已结束（要等回答完）；③ 浏览器是否拦截了下载（地址栏右侧允许下载）；④ 页面是否整页刷新过（再点一次书签）。

**Q：书签脚本安全吗？**
代码全公开（`tools/bookmarklet.js`，网页上也展示）；只在 DeepSeek 页面内同源请求 `chat.deepseek.com`，token 只放进请求头。

**Q：换账号 / 退出登录？**
token 每次点书签时现读，自动跟随当前登录账号。

**Q：会话很多，拉取慢？**
列表立刻到达；详情逐个节流（350ms/个）陆续推送，可边收边导出。默认上限 300 个会话（`MAX_SESSIONS` 可调）。

**Q：Firefox / Safari 能用吗？**
能。本方案只用同源 fetch + postMessage + Blob 下载等通用能力。

**Q：导出的 HTML 里对话内容会被当代码执行吗？**
不会，全部转义（演示数据里故意放了 `<script>` 用于验证）。

**Q：能不能自动保存到桌面？**
不能——那是浏览器扩展才有的能力（需授权目录）。纯前端方案只能下载到「下载」目录。
