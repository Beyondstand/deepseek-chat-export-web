DeepSeek 会话导出工具

在 DeepSeek 网页版点一下书签，会话就出现在这里 —— 导出为 HTML / TXT 文件。

三步上手

  1. 登录 chat.deepseek.com
  2. 把 📚 「DeepSeek 一键导出」书签 拖到浏览器书签栏 （手动创建？）
  3. 在 DeepSeek 页面点击该书签，本页面自动收到你的全部会话
📖 找不到「书签栏」？（Chrome / Edge / Firefox / Safari）
  • Chrome / Edge：按 Ctrl + Shift + B（Mac：⌘ + Shift + B）显示书签栏；或菜单 → 书签 → 勾选「显示书签栏」
  • Firefox：同样是 Ctrl + Shift + B；或「查看 → 工具栏 → 书签工具栏」
  • Safari：顶部菜单「显示 → 显示个人收藏栏」
  • 书签栏是地址框下面的一条横栏，把第 ② 步的书签链接直接拖进去即可
  • 不想显示书签栏也行：点上面的「手动创建？」用 Ctrl + D 收藏，之后从书签菜单里点击一样有效
